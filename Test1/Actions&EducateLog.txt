Since you're neither able to push nor pull-and-push nor merge-pull-and-push:

You can create a new branch on the GitHub repository.
And then:
git add .
git commit -m 'commitName'
And reference that branch in your current directory in Terminal.
git branch -m master branchName
git push -f origin branchName
Your code will be pushed to a new branch.
And then you can merge these two branches.

$ Creating a New Branch from a Remote Branch: (for more clarify: creating a branch that not existed on local repo but exists on remote, and it was updated)
To create a new branch from a remote branch, first, fetch the remote branches, then create and track a new branch based on the remote one. Replace new-branch-name with your desired branch name and remote-branch-name with the name of the remote branch.:
git fetch origin
git checkout -b new-branch-name origin/remote-branch-name

the other example (I wanted update from remote repo the branch named superfeature2 but it not existed on local or was deleted many times ago. So to do it:)
git fetch origin
git checkout -b superfeature2 origin/superfeature2

If you only need to change the message of the very last commit you made:
Command: Run 
	git commit --amend -m "New commit message"     to change it directly from the terminal.
Using Editor: Alternatively, run 
	git commit --amend     without the -m flag to open your default text editor and edit the message there.
